# [AM-02] 캐릭터 이미지 자동 생성

## 상태
완료 (기존 버그 수정)

## 카테고리
Auto Mode

## 경과
자동 생성 버튼 자체(`CharImageStep.tsx`의 `handleAutoGenerate`)는 이미
구현되어 있었음. 다만 생성된 이미지를 `updateCharacter`로만 저장하고
있었는데, `saveNovel()`이 `imageBase64`/`imageMime`을 Firestore 저장 시
걸러내기 때문에 실제 이미지는 저장되지 않고 `imageGenerated: true`
플래그만 남는 버그가 있었음 (AM-01 작업 중 프로덕션 데이터에서 실제로
확인됨 — 기존 캐릭터들 전부 이 상태였음).

`saveCharImage`(Firebase Storage 업로드 + `imageUrl` 저장)를 호출하도록
수정. Storage 업로드가 응답 없이 걸리는 경우에 대비해 타임아웃도 추가
(AM-01의 `lib/withTimeout.ts` 참고).

## 모델
`gemini-3.1-flash-image` (원래 계획이었던 `gemini-2.0-flash-image`는
지원 종료됨 — AI-01 참고)

## 확인 필요
AM-01 문서의 "확인 필요" 항목과 동일 — 배포 후 실제로 이미지가 저장/노출
되는지 확인 필요.
