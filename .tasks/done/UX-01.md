# [UX-01] 사이드바 숨기기 (모바일 반응형)

## 상태
완료

## 우선순위
🔴 긴급 (사용자가 폰에서 작업할 때 사이드바가 화면을 대부분 차지해서 불편하다고 직접 요청)

## 카테고리
공통 UX

## 배경
`Sidebar`가 항상 고정 260px 너비로 떠 있어서, 좁은 화면(폰)에서는 실제 작업
공간이 거의 안 남는 문제. `app/layout.tsx`에 명시적 viewport 메타 설정도
없었음.

## 구현 내용
- `app/layout.tsx`: `viewport` export 추가 (`width: device-width, initialScale: 1`)
- `app/globals.css`: `.sidebar`/`.sidebar-backdrop`/`.mobile-menu-btn`/
  `.sidebar-close-btn`/`.work-panel-grid` 클래스 추가. 768px 이하에서
  사이드바가 `position: fixed` + `transform: translateX(-100%)`로 화면
  밖에 있다가, `.open` 클래스가 붙으면 슬라이드인하는 방식 (데스크톱
  레이아웃은 전혀 안 건드림 — 미디어쿼리 밖에서는 기존과 동일)
- `components/Sidebar.tsx`: `open`/`onNavigate` prop 추가. 헤더에 닫기(X)
  버튼 추가(모바일에서만 보임). 프로젝트 선택 시 `onNavigate()` 호출해서
  자동으로 드로어 닫힘
- `app/page.tsx`: `sidebarOpen` 상태 추가, 헤더에 햄버거 버튼(모바일에서만
  보임) 추가, 탭 뒤에 클릭하면 닫히는 반투명 백드롭 버튼 추가
- `components/WorkPanel.tsx`: Auto Mode 탭의 고정 `300px 1fr` 2단
  그리드를 `.work-panel-grid` 클래스로 옮겨서, 모바일에서는 1단으로
  쌓이게 함

## 검증
- `tsc`, `biome`, `next build` 통과
- Playwright로 실제 브라우저 열어서 확인 (390×844 모바일 뷰포트):
  - 사이드바 기본 숨김, 햄버거 버튼만 노출 ✓
  - 햄버거 클릭 → 드로어 슬라이드인 + 백드롭 ✓
  - 프로젝트 선택 → 자동으로 드로어 닫히고 해당 프로젝트로 이동 ✓
  - Auto Mode 탭의 2단 레이아웃이 1단으로 정상적으로 쌓임 ✓
  - 1440×900 데스크톱 뷰포트에서 기존 레이아웃 그대로 유지되는 것도 확인
    (회귀 없음) ✓
