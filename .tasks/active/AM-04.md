# [AM-04] 자동 모드 스타일 참고 이미지 관리 UI

## 상태
진행 중 (UI 완료, 영구 저장 남음)

## 카테고리
Auto Mode

## 배경
자동 모드 탭에는 스타일 참고 이미지를 올리거나 확인하는 곳이 없어서, 수동 모드 ③-3에서 올려 둔 이미지를
그대로 가져다 쓰고 있었음. 어떤 이미지가 적용 중인지 보이지 않았고, 바꾸려면 수동 모드로 가야 했음.

## 구현
- `components/StyleReferencePanel.tsx` 신설
  - `StyleReferenceFields`: 스타일 프롬프트 + 참고 이미지 관리(여러 장 한 번에 추가, 위치를 유지한 채 교체, 제거,
    번호 표시). 수동 모드 ③-3의 기존 블록을 이 부품으로 교체해 두 화면이 공유
  - `StyleReferenceCallout`: 노션의 "콜아웃 안의 토글" 형태. 접힌 상태에서도 "N장 적용 중"과 작은 미리보기 표시
- `components/WorkPanel.tsx`: 자동 생성 카드 아래에 콜아웃 배치. 자동 생성 중에 바꾸면 이후 장면부터 반영됨
- `lib/store.ts`: `replaceStyleRefImage` 추가 (참고 이미지는 순서대로 전달되므로 교체 시 순서 유지)

## 확인
- [x] 화면에서 펼치기/접기, 3장 동시 추가, 위치 유지 교체, 제거, 접힌 상태 미리보기 동작
- [x] 교체 후 순서 검증 (초록/파랑/빨강 이미지로 색 순서 확인)
- [ ] 실제 이미지 생성에서 바뀐 참고 이미지가 반영되는지 (비용 때문에 미실행)

## 남은 작업
- 스타일 참고 이미지는 여전히 브라우저 메모리 전용이라 새로고침하면 사라짐. 캐릭터 이미지와 같은 방식(Blob 저장 +
  주소만 서버로 전달)으로 영구 저장하면 "이미 올려 둔 이미지가 계속 보이는" 상태가 됨
- 서버로 이미지를 통째로 보내는 구조라 여러 장이면 요청 크기 한도(약 4.5MB)에 걸릴 수 있음 — 영구 저장과 함께 해결
