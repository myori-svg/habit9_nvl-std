# [GR-02] Grammar 탭 — 골든벨 퀴즈 백그라운드 생성

## 상태
진행 중 (구현·로직 검증 완료, 실사용 확인 대기)

## 카테고리
Grammar Studio

## 배경
교재 사진·PDF를 넣으면 골든벨 퀴즈(객관식 + 서술형)를 만들어 PPT에 바로 붙여넣을 수 있게 한다.
Auto Mode처럼 서버가 백그라운드에서 끝까지 진행하고, 결과는 문제별로 "문제"와 "정답"을 따로 복사한다.
GR-01(기획)을 이 티켓이 대체한다.

## 결정
- 탭은 Archive 오른쪽. 소설과 무관하므로 소설을 고르지 않아도 항상 보이고, 소설이 없으면 이 탭만 보인다.
- 입력: 교재 사진 최대 15장 **또는** PDF 1개(섞을 수 없음, 파일당 10MB), 문제 수, 선택 입력인 "추가 요청".
  - 전체 문제 수만 입력하면 객관식 : 서술형 = 2 : 1(기본 15 → 10 + 5). 객관식·서술형 칸에 하나라도 입력하면
    그 합계가 전체 문제 수를 대신한다. 최대 30문제.
  - 사진은 브라우저에서 긴 변 1800px·JPEG로 줄인 뒤 Blob에 직접 올린다(요청 크기 한도 회피).
- 출력은 응답 스키마로 강제(분석 / 문제 / 보기 / 정답 / 해설). 프롬프트 템플릿(`grammar`)은 다른 템플릿처럼
  화면에서 편집할 수 있고, 출력 형식 안내는 코드가 뒤에 붙인다. 문제 수에 따른 구성·난이도 배분은 코드가
  자리표시자로 채운다.
- 복사: 문제별 "문제 복사"(번호 + 문장 + 보기)와 "정답 복사"(정답만), 맨 위에 전체 문제·전체 정답 복사.
  해설과 분석(Unit 제목·문법 범위·대조점·흔한 실수)은 화면에만 보이고 복사에 들어가지 않는다.
- Gemini로 **한 번** 시도하고, 던지거나 응답이 비었거나 형식이 어긋나면 기다리지 않고 바로 OpenAI로 넘어간다
  (빠른 결과 우선). OpenAI로 만든 결과에는 안내 띠·"Gemini로 다시 생성" 버튼·작업 목록 표시가 붙는다.
- 요청한 개수보다 적게 나오면 "N개 중 M개만 나왔어요"만 알리고 자동으로 채우지 않는다.
- 작업은 `grammarJobs` 컬렉션에 저장(폰·노트북 공유). 원본 파일과 결과는 7일 뒤 일일 배치가 삭제한다.
  다시 생성이 실패해도 이전 결과는 지우지 않는다.

## 구현
- `app/api/grammar-run/route.ts`: 접수(`create`/`retry`) 후 `after()`로 진행, `maxDuration = 300`.
  `app/api/grammar-job/route.ts`: 작업·파일 삭제. `app/api/cleanup-grammar/route.ts` + `vercel.json` 일일 cron.
- `lib/grammar-pipeline.ts`·`lib/grammar-generation.ts`: 파일 읽기 → 프롬프트 → Gemini → (실패 시) OpenAI.
  `lib/openai-text.ts`: OpenAI Responses API(사진·PDF 입력, strict JSON 스키마). 모델은 `OPENAI_TEXT_MODEL`
  환경변수, 기본 `gpt-6-luna`(가장 저렴, 대체 경로라 비용 우선).
- `lib/grammar-job.ts`: 문제 수 분배·실행 상태 판정·복사용 텍스트. `lib/grammar-storage.ts`: Blob 읽기·삭제.
- `lib/blob-upload.ts`·`app/api/blob-upload/route.ts`: `grammar/<작업ID>/` 경로와 PDF 허용.
- `lib/firestore.ts`·`lib/store.ts`: 작업 구독·실행 시작/완료/실패/중지(트랜잭션).
- `components/GrammarPanel/`: 입력 폼, 작업 목록, 결과 화면. `lib/prompts.ts`: `grammar` 템플릿·빌더.
